# Lamma Game – دليل التعديل
- **ألوان وأشكال لعبة**: css/themes.css (سطر لكل لعبة، والمتغيرات متشرحة فوق).
- **شكل عناصر لعبة (خانات، أزرار)**: css/games.css.
- **الأساسيات العامة (الأزرار، الألواح)**: css/base.css.
- **كلمات وأسئلة**: ملفات data/ (زوّد عليها من غير ما تلمس الكود).
- **منطق لعبة**: js/<اسم اللعبة>.js، وكل لعبة في ملف لوحدها.
- **لعبة جديدة**: اعمل js/اسمها.js فيه دالة بنفس اسم اللعبة، وضيفها في GAMES (js/core.js) وفي <script> داخل index.html، وضيف ثيمها في themes.css.
- **ألعاب الذكاء**: js/brain.js (القوايم)، js/matches.js (الكبريت)، js/mathpuz.js (ألغاز الأرقام). فوازير الأرقام في data/riddles.js وأشكال الكبريت في data/matchshapes.js.
- **ليدو**: js/ludo.js.
